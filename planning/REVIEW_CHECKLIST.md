# KritvaOS Planning Review Checklist

## Milestone

- [ ] Scope and objective are explicit.
- [ ] Dependencies are explicit.
- [ ] Out-of-scope items are explicit.
- [ ] Task dependencies form a valid execution order.

## Architecture

- [ ] Stable architecture belongs in `docs/architecture/`.
- [ ] Requirements are traceable.
- [ ] Core boundary is respected.
- [ ] I3/I4 boundary is explicit.
- [ ] No speculative abstraction.

## Verification

- [ ] Unit tests defined.
- [ ] Integration tests defined.
- [ ] Sanity test defined.
- [ ] Regression baseline defined.
- [ ] Evidence format defined.

## Documentation

- [ ] Milestone documents agree with requirements.
- [ ] Task acceptance criteria agree with implementation plan.
- [ ] Dependent architecture/verification docs updated.
