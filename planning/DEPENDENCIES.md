# Dependencies

## KOS-I3

- `kritva-core` R1.0
- KOS-I2 Runtime / Application Foundation
- Linux development host
- Existing `kritvaos-community` CMake/toolchain infrastructure

## Explicitly Not Required

- EtherCAT
- CAN
- STM32 firmware
- Nexus/Edge transport
- ROS2/DDS
- PREEMPT_RT
- Physical robot hardware
- Vendor hardware SDKs
